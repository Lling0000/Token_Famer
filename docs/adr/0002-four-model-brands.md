# ADR-0002: 首发目录收敛为四个模型品牌

- 状态：Accepted
- 日期：2026-09-21

## 背景

农场需要让玩家通过花头立即识别模型品牌。原演示目录同时包含 OpenAI、Anthropic、Google、DeepSeek 和智谱，花型与具体模型颜色绑定，导致同一品牌的花外观不一致，也超出了首发希望呈现的品牌范围。

## 决策

首发模型品牌限定为 OpenAI、Claude、Gemini 和 Grok。公开模型目录移除 DeepSeek 与 GLM ID，并加入官方模型 ID `grok-4.6`。现有种植经济等级保持数量、价格、时长和收益不变，被释放的等级改用目录中已有的 OpenAI 或 Claude 模型。

农场花型只由品牌决定。同一品牌下的所有模型共享完全相同的花头、茎叶和配色；具体模型 ID 继续用于模型调用、定价、种植记录和审计。

## 后果

- 玩家只会看到四种稳定且可辨认的品牌花。
- 模型选择器、公开合同、沙箱数据和经济规格必须保持同一目录。
- 后续新增品牌需要更新公开合同、上游 Adapter、品牌花视觉和本 ADR 的后继决策。
