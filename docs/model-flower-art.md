# Model flower art v2

Generated with the built-in image generation tool. The selected transparent PNG is committed at `apps/web/public/assets/model-flowers-v2.png`; calibrated source bounds and root anchors are in `apps/web/lib/model-flower-atlas.json`.

The sheet contains four brands and three growth stages. The renderer uses per-frame source bounds rather than assuming generation produced perfectly equal cells. Each source root anchor maps to the corresponding land center, including in shop previews. Farm drawing keeps nearest-neighbor sampling.

The generated PNG contains transparent pixels with colored RGB data. Its RGB-only thumbnail can appear to have a halo; in-game alpha compositing was inspected to verify that this does not create rectangular colored backgrounds.

Column identities left to right must remain OpenAI jade and cream rosette flower, Claude warm peach/coral sunflower with soft radial petals, Gemini blue-lilac star-shaped clematis, Grok ivory-white pointed chrysanthemum with charcoal center. Keep ALL plants centered at each cell midpoint horizontally, plant root tip at 90% cell height, root point in the center; no terracotta pixels anywhere. Maximum full plant width 62% of cell; mature height about 74% of cell, flowering height 62%, seedling height 35%; align root baselines across each row. Make it polished and charming at 60-90 pixels tall in the actual game. Preserve actual alpha transparency.
