# Token Farmer 第一版产品边界

## 定位与用户

Token Farmer 是邀请制、简体中文、电脑浏览器多人像素农场。模型 Token 同时是模型 API 可用额度和农场种植资源。第一版用于封闭沙箱验证，不提供现金价值承诺。

支持的桌面视口为 `1280x720`、`1440x900`、`1920x1080` 和 `2560x1440`。浏览器内容宽度小于 1180px 时只显示“请使用电脑浏览器”，不提供降级的移动游戏界面。

## 第一版能做什么

### 账号与安全

- 使用邀请码、邮箱和密码注册；完成邮箱验证后才能进入农场。
- 登录、退出、找回密码、管理会话以及启用 TOTP 2FA。
- 创建、命名和撤销最多 5 个 `sk-tf-...` API Key；完整密钥只展示一次。
- 创建或重置 API Key、关闭 2FA 等敏感操作要求重新认证。

### Token 与模型 API

- 持有一份统一 Token Credit 余额；同一个 `sk-tf-...` Key 可在权限范围内调用模型目录中的任意模型。
- 首次完成验证并成功登录时，一次性赠送 `80,000` Token Credit，刷新或并发登录不会重复发放。
- 查看统一余额、预留、不可变账本、API 用量、Token 包和沙箱订单。
- 创建兼容 OpenAI 和 Anthropic 的 API Key，并调用文档列明的普通或流式端点。
- 使用 Mock 上游验证完整扣费、流式、错误和对账流程。

### 农场

- 免费种植新手数据花，固定获得 `100` Token Credit，不参与偷取；也可种植 15 级付费作物。
- 播种时选择模型花型基因，种子成本统一从 Token Credit 扣除；执行浇水、除草、除虫、施肥、收获和清理。
- 从 6 格土地成长至 24 格；升级土地品质，查看成长阶段、事件、成熟倒计时和随机承诺。
- 收获结果可能为 50%、100%、110% 或 145%；收获先成为不可交易 Token 包，手动激活后才进入对应钱包。
- 使用一键维护和一键收获；服务端仍逐块校验并逐笔结算。
- 使用无现金价值的花瓣购买化肥、狗粮和外观；查看丰收花、变异花和图鉴状态。

### 社交与榜单

- 通过好友码、昵称或邀请链接申请好友，接受、拒绝、删除或拉黑，最多 50 人。
- 串门、帮助好友、提升亲密度，在双方允许时放置只延迟成长的恶作剧。
- 对满足条件的成熟地块发起一次概率偷取；结果可能落空，也可能偷到不同数量。
- 查看全服或好友范围的净收获、API 消耗、当前持有榜，支持日榜、周榜和总榜。
- 当前持有榜默认不公开；玩家主动加入后才展示取整后的 Token Score。

### 管理与运营

- 管理邀请、用户冻结、模型与规则版本、奖励准备金、作物、土地、偷取、小狗和排行榜配置。
- 查看订单、上游健康、审计流水；余额调整必须通过 Wallet 补偿流水并填写原因。
- Mock 支付和支付宝沙箱可以完成订单创建、回调验签、查单、幂等入账和退款状态演练。

## 上线条件未满足前受限的能力

- TeamoRouter 仅通过服务端中央 Key Adapter 访问；用户永远不会取得、查看或复用中央 Key。未在环境中显式确认授权时强制使用 Mock 上游。
- 未配置正式支付宝商户、退款、对账和风控前，只允许 Mock 或支付宝沙箱订单，不收真实资金。
- 未完成适用的 ICP 备案、公安备案和专项法律审查前，不将大陆服务器上的域名作为公开生产服务。
- 真实额度的付费随机回报、偷取和促销开关默认关闭。完成资质与法律审查仍需单独 ADR、风险评审和发布批准。

## 第一版明确不能做什么

- 不支持手机适配、微信/QQ 小程序、Windows 或 macOS 原生客户端。
- 不导入 QQ/微信好友，不复用腾讯私有接口、代码、美术或商标性素材。
- 不支持玩家间 Token 转账、市场交易、出售、提现、现金兑换或区块链钱包。
- 不提供牧场、矿山、工会、聊天、赛季市场或复杂活动系统。
- 不承诺种植获利；概率、未处理事件和好友偷取都可能降低结果。
- 不允许管理员直接改余额、直接改账本或绕过支付状态机发放 Token。
- 不记录或展示用户模型请求正文，也不把用户数据用于未说明的训练或营销用途。

## 交付完成定义

只有以下条件全部满足，才可以把相应环境称为已交付：

1. 本地 `pnpm verify` 通过，核心并发和账务不变量测试通过。
2. GitHub 必需检查通过，受保护的 `main` 只能通过 PR 合并。
3. SSH 隧道预部署通过健康、备份恢复、重启和桌面端完整流程验收。
4. 域名上线条件满足后，DNS、HTTPS、外部冒烟、支付回调与回滚再次通过。
